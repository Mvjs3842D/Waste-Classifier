♻️ Waste Classifier

A deep learning–based web app that classifies waste images into Biodegradable and Non-Biodegradable using a trained CNN model.

🚀 Features
🧠 Image classification using MobileNetV2
📷 Upload image and get instant prediction
📊 Confidence score with visual indicator
🌐 Simple Flask web interface
⚡ Runs locally (CPU supported)

🛠️ Tech Stack
Backend: Flask, TensorFlow, OpenCV
Frontend: HTML, CSS, JavaScript
Model: MobileNetV2 (Transfer Learning)

📌 Notes
Uses CPU mode by default (stable)
Model file: waste_classifier.h5
Classes:
B → Biodegradable 🌱
N → Non-Biodegradable ♻️
